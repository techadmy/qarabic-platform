# QA feed (generated)

Written by the «QA journeys» workflow after each nightly or manual run on `main`. Do not edit.
`latest.json` (last run, journeys-summary schema 1), `history.json` (last 60 journey runs),
`runs.json` / `steps.json` (the «Qarabic QA» dashboard's datasets) and `shots/` (the latest
failing step's screenshot). QA personas only; how journeys work: docs/standards/testing.md.
